📖 User Manual

Apa program ini?

Program ini adalah laboratorium kriptografi interaktif yang menggabungkan permainan persegi ajaib \(4\times 4\) dengan teknik enkripsi berbasis permutasi. Anda dapat menyusun angka \(1-16\) hingga semua baris, kolom, dan diagonal berjumlah \(34\) (persegi ajaib). Susunan angka tersebut kemudian menjadi kunci untuk mengenkripsi pesan. Ingat ini hanya sekedar permainan matematika yang hanya menggunakan peranan invers untuk mengembalikan "Cipher text" menjadi "Plain text" atau teks asli setelah dilakukan proses "Enkripsi". Untuk interaktif kriptografi agak serius bisa anda dapat di 🔗 di sini!.

Cara menggunakan

  • Menyusun kunci: Klik dua sel untuk menukar angkanya. Tujuan: capai persegi ajaib (semua garis = 34).
  • Tombol bantuan:
    • 🎲 Acak: mengacak angka secara acak (menghasilkan kunci non-involusi).
    • ↺ Reset: mengembalikan ke urutan 1–16.
    • ⚡ Bantu Selesaikan: langsung membentuk persegi ajaib (konstruksi ab).
    • 🔍 Tampilkan Permutasi: memperlihatkan array permutasi dan apakah ia involusi (self‑inverse).
  • Enkripsi / Dekripsi:
    • Isi pesan pada kotak input.
    • Klik 🧪 Uji Enkripsi‑Dekripsi: program akan:
      1. Menambahkan spasi ( ) di akhir hingga panjang pesan kelipatan 16.
      2. Mengenkripsi setiap blok 16 karakter menggunakan permutasi dari grid.
      3. Menampilkan ciphertext di kotak kiri.
      4. Mendekripsi kembali ciphertext menjadi plaintext dan menampilkannya di kotak kanan.
      5. Memberikan status BERHASIL jika plaintext hasil dekripsi sama persis dengan pesan awal.
  • ✕ Bersihkan: menghapus semua hasil.

Bagaimana enkripsi bekerja?

Setiap grid 4×4 menghasilkan sebuah permutasi \(P\) dengan panjang 16. Untuk setiap blok 16 karakter \(M\), enkripsi menghasilkan \(C\) dengan aturan:

\[ C[P[i]] = M[i] \quad \text{untuk } i = 0,1,\dots,15 \]

Dekripsi menggunakan operasi yang sama:

\[ M[i] = C[P[i]] \]

Karena \(P\) adalah permutasi, operasi ini adalah invers dari enkripsi. Dengan demikian, dekripsi selalu mengembalikan plaintext asli.

Mengapa hasil enkripsi bisa sama dengan plaintext?

Jika permutasi \(P\) adalah involusi (\(P[P[i]] = i\)), maka enkripsi dan dekripsi menggunakan operasi yang persis sama. Persegi ajaib standar (konstruksi ab) menghasilkan permutasi involusi. Untuk melihat efek enkripsi yang berbeda, gunakan tombol 🎲 Acak: permutasi acak umumnya bukan involusi.

Kesimpulan

Program ini membuktikan bahwa setiap susunan grid (baik ajaib maupun acak) dapat menjadi kunci kriptografi yang sah. Dekripsi selalu berhasil mengembalikan pesan asli karena menggunakan properti matematis permutasi. Tetapi ingat ini bukan kriptografi serius, tetapi sekedar permainan matematika.
